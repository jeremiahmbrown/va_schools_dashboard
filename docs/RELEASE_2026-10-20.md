## Rollback

If the released app fails, use the prior committed app and snapshot at
`8f86732` in a separate checkout and deploy it to the **same** shinyapps.io
account and app name with the command in [MAINTENANCE.md](MAINTENANCE.md).
Then load the public URL and verify its snapshot date and core views. The
earlier bundle ID `11589527` records the prior deployed artifact; its ability
to be restored directly in shinyapps.io was not tested here.
