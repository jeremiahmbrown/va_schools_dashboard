# data-raw

This folder is for **repeatable data build scripts** that generate the frozen snapshot
bundled with the Shiny app under `app/data/`.

## Current State
- `build_snapshot.R` is the main entrypoint and is implemented.
- The app ships with a **frozen snapshot** under `app/data/` generated by the build script.
- Optional: attendance-zone build helpers:
  - `build_zone_sources.R` seeds a registry of top divisions by enrollment.
  - `build_zones_sabs.R` generates the dated NCES fallback polygons under
    `app/data/zones/sabs/` when the raw survey files are available.
  - After rebuilding the Roanoke City or County zone files, run
    `python3 data-raw/build_zone_level_cache.py` to update their checked level
    files. A stale cache is ignored by the app.

For statewide attendance-zone work, use `zone_source_inventory.csv` and
`../docs/STATEWIDE_ZONE_PLAN_2026-10-24.md`. Refresh computed coverage columns
with `python3 data-raw/build_zone_source_inventory.py`; research fields and
cohorts are preserved. The old `build_zones_division_sources.R` scaffold does
not emit the GeoJSON schema the app expects and must not publish snapshot files.
The [verified zone import contract](../docs/ZONE_IMPORT_CONTRACT.md) defines
the tracked source manifest, school crosswalk, checks, and safe publication
steps for each new division.
For the reviewed Arlington pilot, run `python3 data-raw/stage_zone_source.py 5100270`,
then `python3 data-raw/import_zone_source.py 5100270` to inspect a candidate.
Use `--publish` only after the source, geometry report, and crosswalk pass
review. Run `python3 tests/check_zone_importer.py` for the failure gates.
The Fairfax validation uses the same stager and importer with division ID
`5101260`. Run `python3 data-raw/build_fairfax_zone_crosswalk.py` after staging;
its explicit aliases and ten exclusions are checked against the frozen school
snapshot. See `../docs/ZONES_COVERAGE.md` for the reviewed source overlap.
Prince William uses division ID `5103130` and
`python3 data-raw/build_prince_william_zone_crosswalk.py`. Its elementary source
is labeled 2025–26; the 2026–27 Woodbridge area is held for a later snapshot
that has a Woodbridge school ID. The app does not link it to Potomac View.

## Intended Inputs (Future)
Place authoritative raw downloads under `data-raw/input/`, for example:
- VDOE School Quality Profile exports (school-level performance + discipline + demographics)
- A stable school identifier crosswalk (state IDs + NCES IDs)
- Division boundaries (polygons) suitable for choropleth mapping

See `build_snapshot.R` for the current set of downloads/transformations and `docs/DATA_SCHEMA.md`
for the snapshot schema.
